# Hello

What this plugin does, in a sentence or two, for someone who just installed it.

## Use

- `lerd hello:greet [site]` prints a greeting for a site.
- `lerd hello:notify` sends a notification, once you allow Hello to.
- Each site's Commands menu gets **Greet**.
- The **Hello** page on the rail and the **Hello** tab on every site show lerd's sites.
